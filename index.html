कई चैनलों के सार्वजनिक वीडियो • एक साझा कंट्रोल पैनल

पहले API key सेट करें: Google Cloud Console में YouTube Data API v3 चालू करके API key बनाएँ। इसे केवल अपने इस्तेमाल के लिए रखें और Google Cloud में वेबसाइट/रेफरर प्रतिबंध लगाएँ। सार्वजनिक वेबसाइट में key को पूरी तरह गुप्त नहीं रखा जा सकता।

तैयार। API key डालें और चैनल लिंक से खोजें, या सीधे वीडियो लिंक जोड़ें।

महत्वपूर्ण: यह डेमो सार्वजनिक चैनल/वीडियो के लिए है। चैनल खोज के लिए Data API key चाहिए। API quota लागू है; search.list की हर कॉल की quota लागत होती है। 100+ सक्रिय वीडियो डिवाइस को धीमा कर सकते हैं। वीडियो केवल उपयोगकर्ता के Play बटन दबाने के बाद शुरू करें। YouTube का अपना प्लेयर और विज्ञापन/ब्रांडिंग बरकरार रहते हैं।
